# mcp-1c-its — MCP-сервер доступа к порталу 1С:ИТС

Даёт ИИ-агенту (ZCode, Claude, Cursor и любому клиенту с поддержкой Model
Context Protocol) поиск и чтение материалов портала [1С:ИТС](https://its.1c.ru)
по вашей подписке: стандарты разработки, документация платформы, БСП,
руководства по типовым конфигурациям.

Сервер сам хранит вход по подписке (логин и пароль лежат в локальном файле и
никак не отдаются агенту), бережно ходит на портал (не чаще запроса в секунду,
кэш материалов на неделю) и отдаёт материалы в виде Markdown со ссылкой на
источник.

## Инструменты

| Инструмент | Назначение |
|---|---|
| `its_search(query, section)` | Поиск по ИТС; по умолчанию по всем разделам (`morphmerged`) |
| `its_get(path)` | Материал в Markdown по адресу из результата поиска |
| `its_sections()` | Каталог разделов для поиска (36 разделов по группам) |
| `its_status()` | Самопроверка: источник учётных данных, состояние сессии |

## Установка

### Вариант 1 — uv (Python не нужен)

Установите [uv](https://docs.astral.sh/uv/getting-started/installation/)
(один исполняемый файл, без прав администратора):

```bash
# Windows
winget install astral-sh.uv
# или PowerShell: irm https://astral.sh/uv/install.ps1 | iex
```

uv сам скачает изолированный Python и зависимости. Для запуска из этого
репозитория:

```bash
git clone https://github.com/<логин>/mcp-1c-its
cd mcp-1c-its
uv sync
uv run mcp-1c-its   # проверка, что сервер стартует (Ctrl+C для выхода)
```

После публикации пакета на PyPI запуск упростится до `uvx mcp-1c-its`.

### Вариант 2 — системный Python (3.10+)

```bash
git clone https://github.com/<логин>/mcp-1c-its
cd mcp-1c-its
python -m pip install .
```

Либо на Windows просто запустите `install.bat` из папки репозитория.

## Учётные данные

Создайте файл `its_credentials.txt` (пример — `its_credentials.example.txt`):

```
ITS_USER=ваш_логин
ITS_PASS=ваш_пароль
```

И положите его в **`%USERPROFILE%\.1c-its\`** (Linux/macOS: `~/.1c-its/`).
Альтернативы — переменная окружения `ITS_CRED_FILE` с полным путём к файлу
или файл в текущей папке (приоритет: окружение → домашняя папка → текущая
папка).

Файл добавлен в `.gitignore` — не коммитите его и не передавайте вместе с
репозиторием. Значения не попадают ни в аргументы инструментов, ни в ответы,
ни в тексты ошибок.

## Подключение к клиенту

Общая запись (stdio):

```json
"1c-its": {
  "command": "<запуск сервера>",
  "args": []
}
```

Конкретные значения `command`/`args`:

- **uv из репозитория**: `uv`, `["--directory", "<путь к репозиторию>", "run", "mcp-1c-its"]`
- **pip-установка**: `python`, `["-m", "mcp_1c_its.server"]`
- **ZCode**: раздел `mcp.servers` файла `~/.zcode/cli/config.json`
- **Claude Desktop / Cursor**: раздел `mcpServers` их конфигурации

После подключения перезапустите клиент.

## Проверка

```bash
python -m mcp_1c_its.check     # или: uv run python -m mcp_1c_its.check
```

Должно показать «Вход в ИТС: успешен» и пробный поиск. Через агента —
попросить «проверь its_status».

## Ограничения и заметки

- Не чаще одного запроса к порталу в секунду; массовая автоматическая выкачка
  — серая зона правил портала, не используйте сервер для неё.
- Кэш материалов — 7 дней, выдачи поиска — сутки (`~/.1c-its/cache/`).
- Если 1С изменит форму входа на login.1c.ru — править функцию `_login()`
  в `src/mcp_1c_its/server.py`.

## Разработка

```bash
python -m pip install -e .          # редактируемая установка
python -m mcp_1c_its.check          # проверка
python -m build                     # сборка пакета (dist/)
```

Структура: `src/mcp_1c_its/server.py` — сервер, `src/mcp_1c_its/check.py` —
проверка, `pyproject.toml` — пакет и точка входа `mcp-1c-its`.
